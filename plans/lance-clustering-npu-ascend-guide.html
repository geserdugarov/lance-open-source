Where an NPU can
make clustering faster.

The promising work is dense vector arithmetic: finding centroids, assigning rows, and encoding vectors. The full job also has to read, move, and write data.

07
A testable path forward

Prove value before expanding scope.

A useful first result is a correct, bounded assignment backend with a measured crossover point. Physical clustering and query serving can follow independently.

Profile & qualify

Pin the Lance commit and device/software tuple. Measure the optimized CPU pipeline. Test real dimensions, null/invalid inputs, and fixed-centroid agreement.

Output: stage timings + capability matrix

Build standard artifacts

Train externally, export compatible models, and let Lance finalize. Compare complete build time and matched-recall query performance on a CPU reader.

Output: usable index + quality/cost result

Integrate row routing

Use a supported stable-partition rewrite or rebuild strategy. Validate multi-fragment values, row IDs, ordering, coverage, and atomic publication.

Output: correct rewrite + measured locality
Which invariants can an accelerator never relax?

Snapshot identity; model/segment identity; metric and preprocessing; uint64 row identity; vector eligibility; valid codebook/rotation layout; stable destination order where FRI requires it; complete index coverage; and atomic publication. Reduced precision is an explicit quality experiment, not permission to lose rows.

Why not move the whole index onto the NPU immediately?

That adds memory residency, filtering, deletion, fallback, serialization, and serving latency concerns before proving the arithmetic benefit. Start with build-time outputs that Lance already understands. lance-cuvs is a useful external-backend precedent, with its own required Lance API baseline.

Does stable FRI routing work on every Lance table?

No. The inspected v14 tagged path accepts address-based tables and rejects stable-row-ID tables. Destination labels preserve the source subsequence within each destination. Arbitrary sorting requires a suitable alternative mapping or index rebuild. See the local support boundaries.

What would justify production work?

Meaningful complete-job acceleration or cost savings at the required recall, bounded host/device memory, and a correct standard Lance result. The report proposes 2× complete-job speedup as an experimental decision target, not a prediction. Record p95/p99 latency and storage traffic when evaluating serving or physical locality.
